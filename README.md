# 나노 NANO

**나만에 의한, 나만을 위한, 나만의 노래방**

현대자동차그룹 차량용 앱 개발 공모전 1차 제출을 위한 클릭형 인터페이스 데모입니다. 정차한 자동차 안을 개인화된 노래방으로 만드는 사용 흐름을 보여줍니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. 이 환경에서는 Node.js 24로 검증했습니다.

```bash
cd /workspace/nano_1.0
npm ci --cache /tmp/nano-npm-cache
npm run dev -- --port 5173
```

기본 개발 서버 포트는 `5173`입니다. 서버는 `0.0.0.0`에 바인딩됩니다.

프로덕션 빌드와 빌드 결과 실행:

```bash
npm run build
npm run preview -- --port 4173
```

## 1분 시연 흐름

### 서버 없이 파일로 시연하기

```bash
npm run export:demo
```

생성된 `exports/NANO-demo.html`을 다운로드한 뒤 Chrome 또는 Edge에서 열면 됩니다. React 코드, 스타일, 폰트, 일러스트가 모두 포함되어 있어 웹 서버와 인터넷 연결이 필요하지 않습니다. 채팅 미리보기에서 스크립트를 차단하는 경우에는 다운로드한 파일을 브라우저에서 직접 여세요. 브라우저가 저장소 접근을 막아도 시연은 가능하며, 이 경우 기록은 창을 닫으면 유지되지 않을 수 있습니다.

### 클릭 순서

1. **인트로:** ‘나만의 무대 시작하기’를 누릅니다.
2. **홈:** 추천 곡, 최근 재생, 즐겨찾기와 정차 상태를 확인합니다. 검색하거나 ‘노래 시작하기’를 누릅니다.
3. **곡 선택:** 검색·장르 필터로 곡을 찾고 ‘밤하늘 드라이브’를 선택합니다.
4. **재생:** 가사, 진행 바, 일시정지, 이전·다음 곡을 확인합니다. 진행 바를 움직이면 가사도 해당 구간으로 이동합니다.
5. **노래방 ON:** ‘마이크 증폭 활성화’ 상태와 보라색 파형을 확인합니다.
6. **리버브 ON:** ‘리버브 효과 적용 중’ 상태, 시안 포인트와 공간감 효과를 확인합니다. 노래방을 끄면 리버브도 해제되며 비활성화됩니다.
7. **세션 마치기:** ‘오늘의 나노 세션’에서 저장·다시 부르기·홈으로 이동을 시연합니다. 저장한 기록은 사이드 메뉴의 ‘내 세션’에서 확인합니다.

## 구현 범위

- 인트로 / 홈 / 곡 선택 / 노래 재생·노래방 / 세션 완료 및 기록 화면
- 5개 가상 곡, 곡·아티스트·장르 검색, 장르 필터
- 재생 타이머, 일시정지, 탐색, 이전·다음 곡, 구간별 데모 가사
- 노래방·리버브 토글과 종속 상태, 모드 배지, 파형·공간감 애니메이션
- 즐겨찾기, 최근 재생, 세션 메타데이터를 `localStorage`에 저장
- 데스크톱·태블릿·모바일 반응형 UI, 키보드 조작, 모션 감소 설정 지원
- 로컬 SVG 앨범 아트·차량 일러스트·한국어 폰트. 설치 후 외부 API나 이미지 서버에 의존하지 않습니다.

## 시연의 한계

**실제 곡 음원 재생, 녹음 저장, 차량 마이크·PLEOS API 연동은 구현하지 않았습니다. 브라우저 마이크 출력 및 DSP는 아래 PHASE 1–3 구현에 포함됩니다.** 곡 재생은 타이머 시뮬레이션이며 마이크 게인·리버브·오토튠은 실제 Web Audio 처리입니다. 차량 연결·PARKED 상태도 고정된 시연용 표시입니다. 실제 차량 상태 감지나 주행 중 차단을 보장하지 않습니다. 곡, 아티스트, 가사는 시연용 가상 데이터이며 음원은 포함하지 않습니다.

세션 저장은 음성이 아닌 곡 정보·시연 시간·선택 모드만 현재 브라우저에 보관합니다. 브라우저 저장소를 지우면 기록도 삭제됩니다. 별도 로그인·서버·API 키는 필요하지 않습니다.

## 구성

```text
src/App.jsx       화면 및 데모 상태 흐름
src/AlbumArt.jsx  재사용하는 SVG 앨범 아트
src/data.js       가상 곡, 가사, 저장소 유틸리티
src/styles.css    차량 디스플레이 테마 및 반응형 스타일
public/cabin.svg  차량 실내 일러스트
```

React 19 + Vite + Lucide 아이콘을 사용합니다. Noto Sans KR은 Fontsource 패키지로 자체 제공하며 패키지에 OFL 라이선스가 포함되어 있습니다.

## 오디오 PHASE 1–3

마이크 안전 제어·선택형 AudioWorklet·진단 UI를 구현했습니다. 초기 게인 0.2, 긴급 MUTE, AEC/잡음 억제 설정과 실제 적용값 확인을 제공합니다. 유선 헤드폰으로 먼저 시험하세요. 소프트웨어만으로 물리적 하울링을 완전히 제거하지 못합니다.

`npm run test:audio`로 엔진 테스트를 실행합니다. 마이크/AudioWorklet에는 HTTPS 또는 localhost가 필요합니다. 기존 독립 HTML도 내보낼 수 있으나 브라우저 보안 정책에 따라 마이크나 오토튠이 제한될 수 있습니다.

[구조·변경 이유·테스트 결과·실기기 측정 절차](docs/AUDIO-PHASES-1-3.md)를 확인하세요. 실제 하울링 억제 효과와 전체 마이크→스피커 지연은 **미측정**입니다. [측정표](docs/audio-measurements.csv)로 전후 비교를 완료한 후 음악 API를 연동합니다.
