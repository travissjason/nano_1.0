# 게인 및 입력 지연 설정 업데이트
초기 게인 0.2 → 0.35 (약 +4.9 dB). 게인 한도, AEC/NS 기본 ON, 최종 Compressor, 자동 감쇠와 긴급 MUTE 유지.
입력 latency 10ms, mono 및 AudioContext와 동일한 48kHz를 지원 브라우저에 선호값으로 요청. 실제 적용값은 진단에서 확인. 이는 실제 왕복 지연이 10ms라는 뜻이 아니다.
유선 헤드폰 저지연 프리셋은 AEC/NS를 OFF 요청한다. 스피커에는 하울링 억제 프리셋을 사용한다.
1초 지연의 원인은 아직 확정되지 않았다. 블루투스 버퍼, Windows ‘이 장치로 듣기’, 외부 모니터링 앱 및 장치 드라이버를 확인해야 한다. 1초 지연 해결이나 하울링 성능 유지는 실제 장치에서 미검증이다.
